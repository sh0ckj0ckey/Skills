Use when implementing a feature, following existing code style, making local structure or layering decisions in an existing codebase, migrating or porting functionality between files, modules, or languages, refactoring legacy or project code, inspecting or reviewing existing code for issues, or writing git commit messages. Do not use for technology selection, broad architecture design, or non-code writing tasks.
