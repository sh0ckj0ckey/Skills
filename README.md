# Skills

✨ Stores sh0ckj0ckey's reusable AI skills, prompts, and workflow rules.

## Overview

This repository collects reusable instructions for AI assistants. Each skill captures a focused set of preferences, rules, examples, and workflow guidance for tasks that come up repeatedly across projects.

## Available Skills

| Skill | Purpose |
| --- | --- |
| `personal-coding-style` | Coding style, refactoring, migration, review, and commit message guidance for C#/.NET, XAML, Vue 3, TypeScript, and Electron projects. |
| `app-copywriting` | Public app publishing copy for GitHub, README files, Microsoft Store listings, feature lists, and release summaries in Chinese and English. |

## Structure

```text
skills/
  personal-coding-style/
    SKILL.md
  app-copywriting/
    SKILL.md
```

## Notes

These skills describe personal defaults. They should guide the assistant while still respecting the current project, existing code style, framework conventions, and task context.
